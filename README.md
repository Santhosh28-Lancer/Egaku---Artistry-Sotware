# Egaku — Image to Art Studio

A Windows desktop application for creating monochrome pencil-style artwork from photographs.

The application source is in the [Egaku](./Egaku/) directory.

- Single pencil illustration workflow
- Local Stable Diffusion 1.5 image-to-image pipeline with a pencil-style LoRA
- PySide6 desktop interface
- Local image processing; photos are not uploaded by the application

See [Egaku/README.md](./Egaku/README.md) for installation and model requirements. The base model weights are not bundled in this repository.
